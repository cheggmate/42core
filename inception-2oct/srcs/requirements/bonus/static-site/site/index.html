Inception Microservices Portfolio

A fully containerized, secure, and resilient web infrastructure orchestrated with Docker Compose on Debian Bookworm.

Visit WordPress (Port 443) Explore Architecture

Project Overview

⚡

Lightweight Containerization

Built using native Linux namespaces and cgroups instead of heavy Virtual Machines, offering near-instant boot times and minimal host overhead.

🔐

TLS & Secret Security

Strict entry point via NGINX supporting TLSv1.2/v1.3 only, paired with in-memory Docker Secrets for sensitive credentials.

💾

Persistent Named Volumes

Decoupled database and website storage mapped to dedicated host directories under /home/jotong/data/.

Core Infrastructure Stack

NGINX Reverse Proxy & TLS Termination Gateway (Port 443)
WordPress Content Management System driven by FastCGI PHP-FPM
MariaDB Relational SQL Database storing WordPress data
